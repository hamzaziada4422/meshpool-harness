# Meshpool 0.0.10: report

Branch `release-0.0.10`, not pushed to `main`, no release published, Actions untouched, no paid model calls (everything ran on the mock model).

## What shipped

**A. Memory you can see**
- Memory v3 store (`memstore.py`): facts with kind, category, scope, status, source, pin, expiry and history; timeline, restore, delete with Undo, conflicts (rules only), review queue, consolidation proposal, health meter, markdown and "How I work" export, portrait (fast model, cached, rule-based fallback).
- Migration from 0.0.9 with a backup in `memory/backup-0.0.9/`, safe to run twice. Old functions, MCP tools and `memory.md` keep working (generated export). The old drop-oldest behaviour is gone.
- Memory page (`memory.js`): portrait, "Meshpool thinks" tray, conflicts, filters, virtualised list past 150 rows, inline edit, keyboard (arrows, Enter, P, Backspace), drag between scopes, projects view, history with Restore, review queue (Y/N), export, memory-off banner.
- In chat: memories chip under a reply (worded "given", not "used"), "What the agent sees" popover with a per-chat leave-out, incognito chats (Ctrl+Shift+N) that read and write no memory, learn nothing and log nothing. "Noted for next time" has Undo. Imported facts wait in the tray.

**B. An agent that notices**
- `insights.py`: nine zero-model detectors, ranking, dedupe, 7-day expiry, quiet hours, per-type switches with acceptance rates, auto-throttle, "less like this" with Undo, reset, `MH_INSIGHTS=0`.
- Suggestions are one quiet line above the composer; next-step chips sit under the reply; at most 2 on home per day, one per type.
- First run from the user's own file names (names only), or sample files; "While you were away"; "Only tell me when something changed" on scheduled tasks and in `schedule_task`.

**C. Receipts and summaries**
- Checks recorded by the real validators and shown live, then one collapsed line; per-turn receipt (time, tokens, agent and reason; dollars only when the user sets prices).
- Chat summaries (hover and search), project brief with Catch me up, "Your work" page (1, 3, 6, 12 months), recap PNG built from counts only, quiet hours in Settings.
- Teach by editing: registry of files Meshpool made, structure diff for decks, workbooks and documents, conservative rules, accepting writes `learned` facts and updates the company font.

**Also in 0.0.10 (requested during the run):** the import step cut to three numbered actions with direct links; Code sessions grouped by folder by default.

## Off, cut or not built

- **Cost in dollars and routing savings** on "Your work": shown as "not measured". The outcome log holds tokens, not prices. Receipts show dollars only if `MH_PRICE_IN` and `MH_PRICE_OUT` are set.
- **Bring-your-own Claude subscription inference:** not built. Forwarding consumer-plan OAuth tokens from a hosted service conflicts with Anthropic's terms for those tokens (decision 20). Piece E (one-click import from other agents) is still available if wanted.
- **Not run here:** Pi and Hermes journeys (not installed in this container), real-model practical journey 32 (paid), LibreOffice-dependent tests.
- All nine suggestion types ship on by default (precision below), with the caveat that the labelled situations are small and written by us.

## Decisions

Full log: `docs/plan/0.0.10-decisions.md`. The ones that shape the product: facts never lost and never overridden by inferred ones; noticed and imported facts wait for a yes; incognito pauses the shared memory tools while it works; detection uses no model; new UI in new files with thin hooks; suggestions are quiet, rare and one per type.
