# Meshpool 0.0.10 plan

Branch `release-0.0.10`. Three tracks. Build order is the order below; each item is built, tested, then committed.
Decisions are in `0.0.10-decisions.md`. Final numbers go in `0.0.10-report.md`.

## Data model
- `memory/facts.jsonl` (one fact per line, schema in the release brief), `memory/log.jsonl` (change timeline),
  `memory/usage.jsonl` (facts given per chat turn), `memory/backup-0.0.9/` (copy of the old files, made once).
- `memory.md` and each project's `memory.md` stay as generated exports for older app versions.
- `insights/cards.json`, `insights/log.jsonl`, `insights/state.json` (per-type stats, mutes, auto-throttle).
- `summaries/` (chat one-liners, project briefs), `artifacts/registry.jsonl` (files Meshpool made: path, checksum,
  structure snapshot), `settings`-style keys for quiet hours and switches in the existing assistant settings file.
