# What people will ask for, and what Meshpool does out of the box

Written so that a request is covered before a customer makes it. "Skill" means a default skill that ships with the app. "Checked" means the result is opened and looked at (picture, audit or test) before Meshpool says it is done.

| People ask for | How it is covered | Checked by |
|---|---|---|
| A landing page, site, portfolio | build-ui, build-website, starter page | ui_audit at 1440, 820, 390, light and dark; screenshots |
| A dashboard or internal tool | build-dashboard, build-app | ui_audit, browser run, reload test |
| An app, calculator, tracker, form | build-app | browser run with the real controls |
| A game or quiz | build-game | keys pressed in the browser, ui_audit on a phone |
| Review or fix how a UI looks | ui-review | audit report, before and after screenshots |
| A chart or graph | make-chart (or native chart in Excel and slides) | view_output |
| A diagram, flowchart, org chart | make-diagram | view_output |
| A logo, icon, banner, social image | make-logo-graphic | view_output at full and small size |
| Slides | make_deck, deck skills | slide pictures, deck checks |
| A spreadsheet or financial model | make_spreadsheet, excel-model, finance skills | workbook checks |
| A Word document, memo, report, PRD | make_document, memo, pdf-report, prd | document checks, view_output |
| A resume, cover letter, invoice, quote | resume-cv, invoice-quote | view_output |
| Merge, split, fill or shrink PDFs | pdf-tools | view_output |
| Resize, convert or compress images | image-tools | view_output |
| Convert any file to another format | convert-files | view_output |
| Gather data from websites into a table | scrape-to-table | source link in every row |
| Research with sources | web_research, research-brief, deep research | links on every fact |
| Analyse a data file | analyse-data, survey-analysis | numbers re-checked against the data |
| Write, test, debug, review code | built-in code tools, debug-issue, write-tests, code-review | tests run |
| Explain a codebase | explain-code | file paths and lines |
| Git: commit, undo, conflicts, pull requests | git-help, pull-request | status shown first |
| Run a long job, dev server or watcher | bash_start, bash_output, bash_stop | output read back |
| Repeat something on a schedule | schedule_task, automate-task, "While you were away" | the first run is done once |
| Email and calendar drafts, inbox work | email-reply, inbox-triage, connectors | drafts only, never sent unasked |
| An HTML newsletter | email-newsletter | view_output at 600 px and phone |
| Translate, proofread, summarise | translate-document, proofread, document-summary | |
| Remember me, my projects and my files | Memory, projects, insights | the user sees and edits every fact |
| Use a website that needs a login | browser tools, Chromium installs itself | page snapshot |
| Run for a very long time without losing the thread | summarising compaction, /compact | 300-step run stays bounded |
| Pick up what I did in another AI app | Import from other agents | secrets stripped, review first |
| Bring in my files from Claude, ChatGPT | Import | nothing sent off the machine |

Added after the product and engineering review: study-pack, cite-sources, query-database, transcribe-audio, resize-for-socials, and a fix so file conversion finds its own ffmpeg and pandoc on a fresh install.

Also built: saved allow and deny rules (`~/.meshpool/permissions.json` and `<project>/.meshpool/permissions.json`), `meshpool -p ... --json` with piped input, notebooks and pivot-table skills, Chromium fetched in the background, shell type told to the agent.

## Not done in 0.0.10, stated plainly

- Sending email, posting to social networks, and live Google Sheets, QuickBooks, Xero, Slack or WhatsApp connections: drafts and files only.
- Image generation (photos and ad pictures). Logos and graphics are drawn as SVG.
- Word tracked changes and margin comments as real revisions (redlines are produced as text).
- Pivot tables in Excel, inline Mermaid and LaTeX in chat.
- Transcription depends on a speech model that is downloaded once; without network the agent says so.
- Bundled ffmpeg and pandoc: fetched by the skill when missing.
- Windows without Git Bash runs commands in PowerShell.

- Cloud sessions and Docker containers (excluded on purpose).
- Hooks on tool calls.
- Notebook cell editing, voice dictation, inline Mermaid in chat.
- Deploying a site to a public address (Meshpool builds and previews it locally and makes a .zip).
- A background scheduler that runs while the app is closed.
- Video, audio and 3D creation beyond converting existing files.
