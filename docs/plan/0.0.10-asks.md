# What people will ask for, and what Meshpool does out of the box

Written so that a request is covered before a customer makes it. "Skill" means a default skill that ships with the app. "Checked" means the result is opened and looked at (picture, audit or test) before Meshpool says it is done.

| People ask for | How it is covered | Checked by |
|---|---|---|
| A landing page, site, portfolio | build-ui, build-website, starter page | ui_audit at 1440, 820, 390, light and dark; screenshots |
| A dashboard or internal tool | build-dashboard, build-app | ui_audit, browser run, reload test |
| An app, calculator, tracker, form | build-app | browser run with the real controls |
| A game or quiz | build-game | keys pressed in the browser, ui_audit on a phone |
| Review or fix how a UI looks | ui-review | audit report, before and after screenshots |
| A chart or graph | make-chart (or native chart in Excel and slides) | view_output |
| A diagram, flowchart, org chart | make-diagram | view_output |
| A logo, icon, banner, social image | make-logo-graphic | view_output at full and small size |
| Slides | make_deck, deck skills | slide pictures, deck checks |
| A spreadsheet or financial model | make_spreadsheet, excel-model, finance skills | workbook checks |
| A Word document, memo, report, PRD | make_document, memo, pdf-report, prd | document checks, view_output |

## Also built after the reviews

Hooks (`PreToolUse`, `PostToolUse`, `UserPromptSubmit`, `Stop`, `SessionStart` in `hooks.json`), saved allow and deny rules (`permissions.json`), instruction files from the home folder and every parent folder with `@file` imports, custom slash commands (`.meshpool/commands/*.md`), `@file` mentions in messages, `meshpool -p ... --output-format json|stream-json --max-turns --allowed-tools --disallowed-tools` with piped input, tasks that run while the app is closed (`meshpool scheduler install`, `meshpool run-due`), a native notebook cell editor, `edit_office_file` (change an existing Word, Excel or PowerPoint file in place, no LibreOffice needed), Chromium fetched in the background, and the shell type told to the agent.

## Not done in 0.0.10, stated plainly

- Sending email and posting to social networks, live Google Sheets, QuickBooks, Xero, Slack, WhatsApp and calendar writes: drafts and files only.
- Image generation. Logos and graphics are drawn as SVG.
- Word tracked changes across differently formatted text (single-format phrases and comments are supported), real Excel pivot objects (formula summaries are built instead), inline Mermaid and LaTeX in chat.
- An operating-system sandbox for commands (a rule-based guard and approvals are used), git worktrees for sub-agents, a VS Code extension (the ACP server works in Zed and JetBrains), voice, share links.
- Public deploy of a site (it is built and previewed locally, and can be zipped).
- Transcription needs a speech model that is downloaded once.
- Windows: unsigned installer, Windows on ARM, and Windows without Git Bash runs commands in PowerShell.
- The scheduler for a closed app is opt-in and polls every 10 minutes; it does not wake a sleeping computer.
