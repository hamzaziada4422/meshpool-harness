# Five-lane swimlane process flowchart

When to use: show which team owns each step of a process and where a decision splits it

Structure: Lane header row across the top with five team names; process shapes sit inside the lanes and are joined by arrows; Yes and No labels mark decision branches.

Framework: swimlane flowchart

Slots:
- slot 1 (table): process name, owner and date strip across the top
- slot 2 (table): short text
- slot 3 (tag, up to 1 words): branch label Yes
- slot 4 (tag, up to 1 words): branch label No
