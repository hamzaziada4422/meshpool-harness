# Weekly project gantt with status legend

When to use: Show which tasks are on track, ahead or at risk, week by week.

Structure: Full-width table with task rows and week columns; accent bars mark task spans, diamonds mark milestones, accent dots mark at-risk items, and a legend sits under the table.

Slots:
- slot 1 (table): Task names in rows with a bar across the weeks, one row per task
- slot 2 (tag, up to 4 words): Section number and name
- slot 3 (legend, up to 3 words): Status label
- slot 4 (legend, up to 2 words): Milestone label
- slot 5 (legend, up to 2 words): At-risk label
- slot 6 (label, up to 3 words): Footer name of the section
