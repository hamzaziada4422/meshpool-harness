# Audit ledger: Meshpool 0.0.9 findings

Every finding from the 0.0.9 bug and benchmark audit, plus the unnumbered items (failed runs `X`, gaps `D`, performance `P`, harness bug classes `H`, missing features `G`, cost and speed targets `K`, CLI parity `CLI`, and `OSS`: bug classes reported in the issue trackers of other open-source agent harnesses, checked against Meshpool). Each one has one owner workstream and ends in one of these states:

- **fixed**: changed in code, with a regression test that fails on the old behaviour
- **already fixed**: fixed before this pass, proven by a test added now
- **not reproducible**: a test that reproduces the reported scenario passes, and is kept
- **open**: not done yet

Per-workstream detail (fix, files, test) is in `docs/audit/ledger/<workstream>.md`.
