# ws04-usage: usage, cost and budgets (incl. nested calls)

Branch `claude/ws04-usage`. Plan: `docs/audit/plans/ws04-usage.md`. Tests live in `app/tests/`; each new behaviour test was run against the code before its fix and failed there.

One usage ledger (`core/usage.py`) receives every model call in the process tree from the provider's own `usage` block: the chat agent, reviewers, the grader, sub-agents, helpers (LiveClient), office engines in their subprocesses (via `MH_USAGE_TASK`), Pi, ACP agents (Codex, Hermes, OpenCode), forge image calls and test calls. Calls are priced per model (user override, endpoint `/models` prices fetched in the background, a per-host and a maintained table); an unknown price shows as unpriced and counts against budgets at the highest table price. Budgets are checked before every call (`usage.reserve`) against the task and its ancestors, counting calls in flight. One model-call gate (`core/gateway.py`) covers every call.

Notes
- Outside agents on the ChatGPT sign-in go through the local relay; the relay does not record, the agent does (exact for Pi; for an ACP agent that reports no usage, an estimate flagged as unreported).
- Models on the Meshpool gateway with no published price (e.g. gpt-6-luna) show as unpriced; prices can be set per model with `MH_PRICES`.
