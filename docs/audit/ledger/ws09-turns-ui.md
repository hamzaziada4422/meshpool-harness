# ws09-turns-ui ledger

Base: `370427e` (audit branch + ledger + fsio). All items reproduced on 0.0.12 and still reproduced on this base (the base
already set `working` under the lock before the capability wait and emitted `turn_end` on two early returns, but the
idle check in `send()` stayed unlocked, the key check still ran before any claim, and nothing tied approvals, questions
or the interrupt flag to a turn). The fix is one explicit state machine in `Session` (turn token, lock-guarded
transitions, `_end_turn` as the only exit, unique approval ids, a resume step that closes what was open) plus the page
reconciling with what the server says it still waits on. Tests: `app/tests/test_ws09_turns.py` (backend) and
`app/tests/test_ws09_ui.py` (real app, mock model, Chromium). Every listed test fails on the base and passes here.
