# ws17-acp: outside harnesses (ACP, Pi, Hermes, Codex, OpenCode)

Every item reproduced on the audit base (370427e3) before the fix: each test below was run with the fix reverted and
failed, then passed with it. Tests: `app/tests/test_ws17_acp.py` (fake ACP agent and fake Pi RPC binary) and
`app/tests/test_ws17_real_harness.py` (real Pi 0.73.1 and codex-acp 2.6.0 against local mock models; skipped when
not installed). Paths are under `app/meshpool_harness/`.
