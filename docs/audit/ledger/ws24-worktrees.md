| G-11 | fixed | No isolation existed: chats, sub-agents and scheduled runs all worked in the folder itself, so parallel agents edited each other's files and each turn's checkpoint saw the other's edits (Undo then refused both, M18-02). App: "Work in an isolated copy (worktree)" in the Code composer menu, a suggestion when another open chat works in the folder, an "Isolated copy" panel (diff, Merge, Discard), chats listed under their source folder, delete prunes the copy. Sub-agents: two or more editing sub-agents each get a copy and the parent applies them in order; conflicts are reported in the tool result. Scheduled runs on a git folder run in a copy (seam `assistant.run_folder`).
