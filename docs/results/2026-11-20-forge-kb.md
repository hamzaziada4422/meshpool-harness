# Forge knowledge base: results, 2026-11-20

Renderer-only A/B on the frozen briefs (`docs/results/2026-11-20-forge-kb-baseline.md` has the method). Same slide
JSON before and after each change, density balanced, first pass, no model calls. Tokens, dollars and repair rounds
are not measured (`docs/plan/FORGE_KB_BLOCKERS.md`): every change below adds no model call, so its cost per deck is
unchanged by construction.

Dev split: 8 briefs, 76 slides. Baseline on dev: 92 first-pass failures (P20 32, P13 37, P14 10, P7 6, P11 6, P10 1),
P20 worst slide median 0.505 (per deck), 22 of 68 content slides over 20% empty.

## A. Calibration from the reference decks

Change: P11's verb lexicon gains imperative and present-tense verbs ("approve", "endorse", "submit", "receive" and
62 more, 66 in all) that count only as written or with -s, never as -ed or -ing forms (those are mostly adjectives in topic
labels). No numeric threshold changed: the 130 reference decks do not clearly dispute any (baseline file, "Thresholds
the reference decks dispute").

| | Baseline | After |
|---|---|---|
| P11 failures (dev) | 6 | 0 |
| All first-pass failures (dev) | 92 | 86 |
| Other rules | | unchanged |

Evidence: on the dev briefs, all 6 P11 failures were sentences with a verb the lexicon missed. On 4,138 English
reference titles the verb share moves from 59.8% to 60.5%. A sample of 33 newly passing reference titles was read:
the ones still wrong came from words that double as nouns ("phases", "guide", "release"), which were then removed.
A unit test pins both sides (sentences pass, topic labels such as "Three priorities for the fourth quarter" and
"Operating division trends" fail).
