# Build game

1. One HTML file with inline JavaScript. Keyboard and touch controls both work. A start screen, a score, a game over screen and a restart button.
2. Keep the game loop on requestAnimationFrame; no libraries unless asked.
3. Open it with the browser tools, press the keys, and take a snapshot to check the score changes and game over appears. Run ui_audit for layout on a phone.
4. Fix what you find, then reply with the path and the controls in one line.

Rules: Write in plain sentences, no em dashes. Save results in the project's "Meshpool outputs" folder unless the user names a place. Look at every visual result with view_output (or ui_audit for web pages) before you say it is done. Reply with the file path and two sentences on what it is.
