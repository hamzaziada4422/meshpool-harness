# Research brief

Do the asked thing first, at the size asked. One deliverable: the brief. A "short report" is one to two pages. Research only as deep as the question needs: one web_research call, then at most four fetch_url reads. Do not search again once every number you will state has a source.

1. Restate the question in one sentence and list the three to five things you need to find out.
2. Search the web for them (web_research first; fetch_url or the browser tools only for pages that matter). Prefer primary sources: official sites, filings, documentation, papers.
3. Note every fact with its source URL. Do not state numbers you could not find a source for.
4. Write the brief in Markdown: a two-sentence answer first, then a short section per finding, then a Sources list.
5. Save it as one Word file with make_document (Meshpool Office) in the project folder, named after the topic. No PDF copy or extra versions.
6. Reply with the answer in two sentences and the file name.
