# Make diagram

1. List the boxes and the arrows first in plain words. Fewer than twelve boxes; split into two diagrams if more.
2. Write an SVG by hand (rectangles, text, arrows with a marker) in a 1200 by 700 viewBox, or an HTML page with inline SVG. Use one font, two colours and the same box size for the same kind of thing.
3. Open it with view_output. Fix text that overflows a box, arrows that cross text and boxes that overlap, then look again.
4. Save the SVG and a PNG of it. Reply with both paths.

Rules: Write in plain sentences, no em dashes. Save results in the project's "Meshpool outputs" folder unless the user names a place. Look at every visual result with view_output (or ui_audit for web pages) before you say it is done. Reply with the file path and two sentences on what it is.
