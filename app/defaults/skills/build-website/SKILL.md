# Build website

1. Read the build-ui skill first and copy its starter.html as the base of every page.
2. Ask one question only if you do not know what the business or person does. Use the user's real name, words and files; leave out anything you would have to invent.
3. Make index.html plus one file per page, a shared style.css, and the same header and footer on every page. Forms post nowhere: show a clear thank-you message with JavaScript and say that a form service must be connected to receive them.
4. Run ui_audit on every page until it reports no problems.
5. Show the user how to open it: the path of index.html. Offer to zip it (make a .zip with Python) or to run it on a local port with bash_start for a live preview.

Rules: Write in plain sentences, no em dashes. Save results in the project's "Meshpool outputs" folder unless the user names a place. Look at every visual result with view_output (or ui_audit for web pages) before you say it is done. Reply with the file path and two sentences on what it is.
