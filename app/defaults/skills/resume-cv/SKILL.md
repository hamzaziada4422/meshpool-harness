# Resume cv

1. Take the facts from the user's files or words only. Never invent a job, date, degree or number; ask for what is missing in one message.
2. One page for under ten years of experience. Name, contact, a two-line summary, experience with results first (verb, what, number), skills, education.
3. Build it with make_document, then convert to PDF and open it with view_output to check it is one clean page.
4. For a cover letter, three short paragraphs: why this company, why you, the ask.

Rules: Write in plain sentences, no em dashes. Save results in the project's "Meshpool outputs" folder unless the user names a place. Look at every visual result with view_output (or ui_audit for web pages) before you say it is done. Reply with the file path and two sentences on what it is.
