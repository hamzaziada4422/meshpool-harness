# Resize for socials

1. Sizes: Instagram square 1080x1080, portrait 1080x1350, story and reel 1080x1920, LinkedIn 1200x627, X 1600x900, Facebook cover 820x312, YouTube thumbnail 1280x720, favicon 512x512.
2. For each size, crop around the subject (never stretch) and keep text and logos inside a 10 percent safe margin. When text sits on the image, rebuild the layout in HTML or SVG for that size and render it with view_output's browser rather than scaling a flat image.
3. Make a contact sheet of all sizes on one page, open it with view_output, fix anything cut off, and then write the files named by size.

Rules: Write in plain sentences, no em dashes. Save results in the project's "Meshpool outputs" folder unless the user names a place. Look at every visual result with view_output before you say it is done. Reply with the file path and two sentences on what it is.
