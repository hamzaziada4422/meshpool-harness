# Make logo graphic

1. Ask for the name and the feeling only if missing. Make three distinct directions, not three colour variations.
2. Draw each as SVG with shapes and text converted to simple paths or a system font. One to two colours. It must work in one colour and at 32 px.
3. Put all three on one page and open it with view_output at full size and shrunk to small. Choose what reads best and say why in one line.
4. Export the chosen one as SVG and PNG (transparent and on white) with Python (cairosvg if present, else render with the browser and view_output's picture).
Never copy a known brand's mark.

Rules: Write in plain sentences, no em dashes. Save results in the project's "Meshpool outputs" folder unless the user names a place. Look at every visual result with view_output (or ui_audit for web pages) before you say it is done. Reply with the file path and two sentences on what it is.
